# Changes

### Compatibility and Fixes

- Updated compatibility for the latest Skillshot City build
- Fixed shared name colors in leaderboards, chat, cars, and killfeed
- Fixed draft highlights disappearing when picking multiple queued skills while holding Ctrl
- Added a configurable mod menu keybind in Interface settings
- Fixed menu conflicts affecting Freecam settings, private module renaming, and Credits

### Shared Cosmetics

Following discussion with the game's developer, sharing custom colors will now depend on your DLC and active Acid Pass. This helps preserve the value of the game's paid cosmetics while still letting you customize how your own name looks.

- **No DLC or active pass:** custom colors and gradients are only visible to you
- **Any non-pass DLC:** share a plain color with other mod users. Gradients can still be used locally
- **Active Acid Pass:** share plain colors, custom gradients, and rainbow colors with other mod users
- If your Acid Pass expires, your sharing access returns to what your other owned DLC allows
- Everyone can still see other players' shared colors with **See others' colors** enabled, regardless of purchases
- Added a separate popup explaining your current access, with rainbow text for Acid Pass
- Restart the game after purchasing DLC or a pass to refresh your access. If ownership cannot be verified, your custom colors remain local until it can be checked

### Installation

Download **SSC-Mod-Menu-Setup.exe** below and select **Install** or **Update**. Your existing settings and custom sounds are preserved.

You can also update through the in-game prompt when this release becomes available.

For Linux / Proton, follow the [installation instructions](https://github.com/Epiano7/SSC-Mod-Menu/blob/main/linux/README.md). Linux support remains experimental.
