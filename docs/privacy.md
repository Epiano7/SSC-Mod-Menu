# Anonymous-mode protection

In **Misc**, enable **Respect anonymous mode** to follow the game's **Use Anonymous Name** setting. It defaults on.

Protection pauses shared color publication and reception, Auto Messages, custom Quick Chat, Discord activity and map-capture uploads. Local-only name colors remain available. Your saved feature preferences are preserved. Ordinary game chat and the native quick-chat wheel remain available. A customized wheel that was already open may need closing and reopening to use its ordinary entries.

Local recording and saved match reviews remain available. **Match Summary → Use Game API** defaults on and independently controls game API lookups and associated review-data collection, including while anonymous mode is active. Disable it to keep reviewing recorded stats without new API requests; result-dependent scoring may be unavailable. Extended draft research follows its separate upload toggle and access checks. Anonymity does not erase recorded identity or pause enabled build-data submissions. API requests include account/match identifiers and are visible to the API operator. Local recordings, screenshots and saved reports can still contain identity information; this feature does not rewrite them or hide unrelated game/Steam/Discord information. Build-sharing codes contain skills rather than account data.

Entering protection holds map-capture uploads. After leaving protection, use **Resume held uploads** in Misc to allow captures again. The hold survives a normal settings save and restart. Messages canceled by protection are discarded, not replayed.

The mod requests removal of previously shared colors. Other PCs may retain cached colors until expiry. Activity already delivered or a request already sent cannot be recalled. This is a safeguard for identifying mod features, not a guarantee of anonymity.

If a game update invalidates anonymous-mode detection, the menu reports that detection is unavailable and keeps protection on while Respect anonymous mode is enabled. The update checker remains independent.
