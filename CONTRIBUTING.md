# Contributing

Open an issue describing the problem, game version, module and steps to reproduce. For HUD issues, include resolution, UI scale and a screenshot if possible. Avoid sharing account information, logs containing private data, or game assets.

Keep changes focused. Run the relevant tests and preserve native calling conventions, rendering state and exact-build checks. Installer changes must retain manifest ownership, modified-file preservation and rollback behavior. Document what was tested and what still needs gameplay verification.

Propose new modules in an issue before a large implementation. Avoid duplicate controls already provided by the game. Do not include executable game files, extracted assets, personal settings or local build outputs in contributions.
