# Contributing

Open an issue describing the problem, game version, module and steps to reproduce. For HUD issues, include resolution, UI scale and a screenshot if possible. Avoid sharing account information, logs containing private data, or game assets. I will try my best to check PRs and issues regularly but if it's been a day or two and there's no response, you can reach out to me on Discord (epiano7) and let me know to check it out. For feature requests, you can make an issue with the 'feature request' tag or make a PR if you already have the changes implemented. If you do choose to make a PR with a custom build, please provide some screenshots or a short video of the feature; I will manually check the build out as well.

## The Golden Rule
If the feature could give an inherent advantage to players over vanilla players, **please include that in the PR/Issue!**
