# Security Policy

## Supported Versions

The most recent release is eligible for reporting 


| Version | Supported          |
| ------- | ------------------ |
| latest release | :white_check_mark: |
| any build predating latest   | ✅*  |
*earlier builds will be pulled if any security issues are present

## Reporting a Vulnerability

Please use Github's Private Vulnerability Reporting feaure instead of the standard issues tab for safety reasons.
In the report, include the vulnerability, what it affects in terms of data, and how important is it to patch.
Also include a suggested patch if you had one in mind for me to review.
